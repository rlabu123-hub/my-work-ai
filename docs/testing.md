# 구현 및 검증 결과

검증일: 2026-10-21 (Asia/Seoul). 이 문서는 현재 클라우드 인스턴스에서의 결과이며 공개 배포나 새 환경 복원을 검증했다는 뜻이 아닙니다.

## 구현한 기능

- Today: 서울 날짜/시각, 오늘 업무·완료율·진행 프로젝트·지연 수, 근거가 있는 TOP 3, 시작/완료, 전체 목록, 일정 타임라인, 가용 시간.
- 업무: 생성·수정·삭제·보류·완료, 검색·상태 필터, 마감/시작일, 수동 우선순위, 중요도/긴급도, 예상/실제 시간, 메모, 프로젝트/목표, 드래그 순서 변경, 선행 업무 선택.
- 선행 업무: 미완료 선행 업무가 있는 작업을 TOP 3에서 제외. SQL 트랜잭션으로 순환 참조를 거절. 날짜 변경/삭제는 사용자 확인.
- 목표/프로젝트: CRUD, 장기→월간→주간 상위 목표 연결, KPI 목표·실적·담당자·달성률, 프로젝트 남은 업무/지연 표시.
- Supabase: 이메일 PKCE 로그인, 서버 인증, PostgreSQL, 사용자별 RLS, 소유권 복합 FK, 변경 이력, Realtime 구독, private audio Storage. 현재 인스턴스는 **미연결**.
- AI: Responses API 연결 코드, 실데이터 조회, 함수 호출로 업무 변경 제안→확인 후 반영, 구조화된 우선순위 분석과 이유 저장, 수동 우선순위 존중. 미설정 시 로컬 규칙 기반 안내를 명시.
- 회의: 모바일 반응형 녹음 UI, 동의/마이크 권한, 일시정지·재개·종료, 시간, 재생·다운로드·업로드, 화면 숨김 시 일시정지, private 음성 저장 코드, 전사 API, 녹취 편집, AI 회의록/실행 과제 추출 코드, 업무 추가 폼, 기록 저장·검색·삭제·Markdown.
- MCP: 10개 SDK 도구, Streamable HTTP, OAuth discovery, Supabase OAuth 2.1 동의 UI/PKCE 연동, JWT 발급자·서명·리소스 audience·client grant 검증, 읽기/쓰기 제안 권한 분리, 앱 승인 트랜잭션, 권한 해제.
- 캘린더: 일/주/월, 연결 업무, 시간 블록 CRUD, 일정 중복 경고, 한국 시간 편집.
- 알림: 사용자가 권한을 허용하면 **앱이 열려 있는 동안** 일정 시작/마감 15분 전 브라우저 알림. 기본은 꺼짐.
- 리뷰: 주간/월간 집계와 규칙 기반 개선 제안, Markdown 및 브라우저 인쇄/PDF.
- PWA: manifest, 192/512 PNG 아이콘, standalone 설치 설정, 프로덕션 서비스워커와 오프라인 안내. 인증 페이지/업무 데이터/API/음성/토큰은 서비스워커 캐시에 저장하지 않음.
- 로컬 체험: API 키/인증 설정 없이 수동 업무 관리, 브라우저 내 영속 저장 및 탭 간 반영, 동의 후 샘플 추가. 이는 클라우드 동기화가 아님.

## 실행한 자동 검증

| 명령/검증                              | 결과            | 범위                                              |
| -------------------------------------- | --------------- | ------------------------------------------------- |
| `npm ci --cache /workspace/.npm-cache` | 통과            | lockfile로 재설치                                 |
| `npm run build`                        | 통과            | 프로덕션 빌드와 포함된 TypeScript 검사            |
| `npm run typecheck`                    | 통과            | 전체 TS                                           |
| `npm test`                             | 9 통과 / 0 실패 | 도메인 7, PostgreSQL/RLS 1, MCP SDK 1             |
| Playwright 데스크톱                    | 6 통과 / 0 실패 | 아래 시나리오                                     |
| Playwright 모바일 viewport             | 6 통과 / 0 실패 | 같은 시나리오, Chromium 기반 iPhone 13 에뮬레이션 |
| 개발 서버 브라우저 로딩                | 통과            | 로딩 종료 및 인터랙티브 업무 공간 확인            |
| 화면 확인                              | 완료            | 1440px 데스크톱 및 390px 모바일 캡처 검토         |

브라우저 시나리오:

1. 업무 등록→새로고침 보존→완료→수정→삭제, opt-in 샘플 데이터, 일정 등록, 로컬 AI 대체 안내.
2. 녹음 동의 전 시작 차단, 수동 녹취 저장→다시 열기→삭제.
3. 동일 브라우저 두 탭의 업무 반영, 미설정 AI/MCP API가 503으로 명확히 거절.
4. Chromium **가상 마이크**로 시작→일시정지→재개→종료, 재생 가능한 blob 파일 생성. 실제 스마트폰 마이크나 iOS Safari 검증은 아님.
5. 선행 업무가 미완료일 때 후속 업무 TOP 3 제외, 완료 후 추천에 나타남.
6. 프로젝트 생성, KPI 목표 생성·프로젝트 연결·실적 수정·달성률 갱신·목표 삭제.

DB 테스트는 PGlite의 실제 PostgreSQL 엔진에서 **001~004 마이그레이션 SQL을 실행**합니다. 테스트 부트스트랩이 auth/storage 역할·함수와 Realtime publication의 스키마 계약을 제공합니다. 사용자 A/B 격리, 외부 소유 프로젝트 FK 거절, OAuth 무권한/읽기 전용/쓰기 제안 제어, 앱 세션 전용 승인, 동일 승인 재시도 시 한 건 생성, 권한 해제, OAuth audience hook, 선행 업무 순환 시 전체 트랜잭션 롤백을 검증합니다. 실제 Supabase Auth 메일, Storage 네트워크, Realtime WebSocket 서비스를 테스트한 것은 아닙니다.

MCP SDK 테스트는 실제 Client와 InMemoryTransport로 초기화/도구 목록/입력 검증/권한 오류를 실행합니다. DB는 테스트 대역이며 실제 DB 권한은 위 PostgreSQL 테스트에서 별도 검증합니다. 실제 ChatGPT가 원격 HTTPS 서버에 연결했다는 뜻은 아닙니다.

Playwright 다운로드는 기본 클라우드 네트워크에서 403으로 차단되어 기존 `/usr/bin/chromium`을 사용했습니다. 도메인 허용 요구사항은 환경 설정 초안에 저장했습니다. 검증을 끄거나 실패한 테스트를 skip 처리하지 않았습니다.

| 모바일 완료 → PC 반영        | 같은 제약. 탭 간 로컬 반영 테스트와 구분                                           |
| 업무 10개 중 TOP 3와 이유    | 규칙 엔진 자동 테스트 통과. OpenAI 결과의 품질/실제 호출은 미검증                  |
| 모바일 음성 → 전사 → 회의록  | 브라우저 녹음 자동 테스트 통과. 실제 OpenAI 전사/회의록 호출 미실행                |

| ChatGPT MCP 등록 → 앱 반영   | SDK/SQL staging·승인·중복 방지 통과. 실제 OAuth/ChatGPT/Realtime end-to-end 미실행 |
| ChatGPT 실시간 조회          | 같은 DB 조회 코드. 공개 서버/토큰으로 실제 조회 미실행                             |

필요한 외부 설정: Supabase 프로젝트·공개 URL/anon key·마이그레이션·이메일 리디렉션, 서버 OpenAI 키, 공개 HTTPS 배포, OAuth 서버/클라이언트/Hook, ChatGPT의 지원되는 MCP 연결 환경. 비밀키는 채팅으로 보내지 말고 호스팅/환경 설정에서 입력하세요.

## 아직 완료하지 않은 요구사항

- 24MB 초과 장시간 음성의 자동 분할·청크 재시도·비동기 전사. 현재는 명확한 제한 안내와 안전 종료만 제공.
- Vercel 대용량 본문 제한을 피하는 private 직접 업로드+작업자 전사.
- Google Calendar OAuth 및 외부 캘린더 양방향 동기화.
- 백그라운드/앱 종료 후 push, 서버 스케줄러 알림. 현재 브라우저 알림은 전경 전용이며 실기기 수신 미검증.
- 주간·월간 리뷰 전용 AI 개선 분석, 이력 기반 반복 지연 추적. 현재 리뷰는 규칙/집계 기반이며 AI 채팅에서 일반 분석 요청 코드는 제공.
- 공식 Sign in with ChatGPT의 계정 등록 자격/승인 확인 및 로그인 구현.
- 대규모 목록의 페이지네이션과 서버 검색, 녹음 데이터 보존 정책/정기 백업, 운영용 장기 모니터링.
- MCP 최근 성공 요청 시각/오류의 영속 통합 로그. 현재 데이터 갱신 시각, 업무 변경 이력, 승인 이력, 권한/대기 요청을 표시.
- 실서비스 배포와 신규 클라우드 작업으로의 스냅샷 복원 확인.

따라서 **Phase 1을 중심으로 실행 가능한 앱과 Phase 2~4 연결 코드를 제공한 상태**이며, 모든 실서비스 연동을 완료했다고 보지 않습니다.

## 테스트 실행 주의

Playwright는 Supabase 공개 환경 변수가 없는 로컬 체험 모드 전용입니다. 실서비스 자격 증명이 들어 있는 프로젝트/사용자 DB를 대상으로 자동 브라우저 테스트를 실행하지 마세요. 클라우드 통합 검증은 위 별도 인수 절차를 따릅니다.
